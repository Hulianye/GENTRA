# Data preparation

Pretraining and zero-shot evaluation use the seven source bundles and four evaluation bundles generated by `python scripts/prepare_data.py --stage all`. By default this reads `data/raw/`, writes 8–32 Hz, 250 Hz, 1000-sample bundles to `data/source/`, and writes EA caches to `data/cache/train/` and `data/cache/eval/`. Set `GENTRA_RAW_ROOT`, `GENTRA_SOURCE_ROOT`, `GENTRA_TRAIN_CACHE_DIR`, or `GENTRA_ZS_CACHE_DIR` to relocate them. `python scripts/prepare_data.py --stage validate` checks those bundles.

Downstream full fine-tuning uses **different input files**. From legally obtained MOABB-accessible recordings, run `python scripts/prepare_downstream_data.py` to create `BNCI2014001.pkl`, `BNCI2014004.pkl`, `BNCI2015001.pkl`, and `Zhou2016.pkl` under `data/downstream_raw/`. Set `GENTRA_RAW_ROOT` to the MOABB/MNE raw-data directory and `GENTRA_DOWNSTREAM_RAW_ROOT` to change the output directory, or pass `--raw-root` and `--output-dir` explicitly. The exporter uses the original dataset-specific session, label, filter and crop choices, checks dimensions and metadata, and writes `EEGData` bundles with `split_method=LOSO`. It can also process a subset, for example `python scripts/prepare_downstream_data.py --datasets BNCI2014004`.

These bundles are the inputs to the downstream preprocessing stage; the fine-tuning command then applies its scenario-specific 8–32 Hz filter, CAR/no-CAR operation, resampling, 4-second crop, and Euclidean alignment. Zhou2016 is already 8–32 Hz filtered at the export stage, matching the original downstream input. Do not substitute the `data/source/` evaluation bundles: those are already cropped, and reprocessing them changes the experiment.

The downstream command generates scenario-specific caches in `data/cache/downstream/` and validates their preprocessing metadata on reuse. The original EEG recordings and prepared data bundles are not included.

Expected input bundle dimensions and sampling rates for the released scenarios:

| Bundle | Trials × channels × samples | Sampling rate | Subjects |
| --- | ---: | ---: | ---: |
| BNCI2014001 | 2592 × 22 × 1000 | 250 Hz | 9 |
| BNCI2014004 | 1400 × 3 × 1126 | 250 Hz | 9 |
| BNCI2015001 | 2400 × 13 × 2561 | 512 Hz | 12 |
| Zhou2016 | 1800 × 14 × 1251 | 250 Hz | 4 |

The source session selection is BNCI2014001 `0train`, BNCI2014004 `3test`, and BNCI2015001 `0train` (named `0A` in MOABB 1.5.0); Zhou2016 uses all available sessions. The exporter uses MOABB filters of 0.1–75 Hz, 0–120 Hz, 0.1–75 Hz, and 8–32 Hz respectively. The downstream 4-second crop is applied by the fine-tuning preprocessing stage; the BNCI2014001 source bundle already contains 1000 samples. Labels are contiguous integers in the order left hand/right hand/feet/tongue for BNCI2014001, left/right for BNCI2014004, right/feet for BNCI2015001, and left/right/feet for Zhou2016. The validated exporter environment uses MOABB 1.5.0 and MNE 1.12.1.
